# Domain docs

This is a single-context repository.

Before exploring or changing the site, read:

- `CONTEXT.md`;
- applicable ADRs in `docs/adr/`;
- `docs/architecture.md` when changing layouts, collections, wiki links,
  backlinks, or article navigation.

Use the vocabulary in `CONTEXT.md` in issues, specs, tests, and implementation
notes. Surface any conflict with an existing ADR instead of silently overriding
it.

```text
/
├── CONTEXT.md
├── docs/

└── ...
```
