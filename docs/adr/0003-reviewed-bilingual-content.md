# ADR 0003: Use reviewed translation pairs with original-language fallback

Every work is an original plus an optional, explicitly paired Chinese or
English translation. Listings always carry bilingual discovery metadata;
readers selecting an unavailable translation see the original language rather
than hidden content or an unreviewed machine translation. AI may draft a
translation, but only author-reviewed translations are public, preserving
quality without delaying the original work's publication. Wiki links preserve
their source syntax but resolve to the selected-language version of their
target whenever that version exists.
