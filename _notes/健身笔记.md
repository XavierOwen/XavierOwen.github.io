## 减脂好活

1. 不再少食多餐，防止胰岛素分泌异常
2. 警惕低升糖水果，因为果糖和蔗糖的存在。尽量吃莓类
3. 多吃富含膳食纤维的，如果一定吃零食的话
4. 训练后不吃蛋白粉，可以在饭点前饿的时候补充
5. 拒绝0卡气泡饮料，会引发胰岛素抵抗，宁愿和有糖的气泡饮料
6. 找到属于自己的燃脂碳水，研究结果和实际个人反应不一样的
7. 米饭的话，太粘的升糖快，冷藏后的过夜处理也可以减少直链淀粉
8. 玉米有的品种以及其他薯类粗粮也有高升糖亚种，同样，粘粘的少吃
9. 二八原则。控制80%的饮食，剩下20%自由吃
10. 食物指数表格

## 减脂过程

1. 消水肿
   - 清淡饮食
   - 规律作息
   - 多喝水
   - 一周左右
2. 消内脏脂肪
   - 戒甜食、零食（糖油）
   - 吃饭先吃纤维素，后蛋白，最后糖
   - 少久坐多走动
   - 有氧
   - 适当增肌
   - 睡眠、疲劳管理
3. 消皮下脂肪
   - 瓶颈期
   - 力量训练

## 家庭哑铃全套

1. 胸
   1. 厚度：哑铃卧推4*10-15
   2. 外侧：哑铃夹胸4*10-15
   3. 内侧：哑铃对握推4*10-15
   4. 下侧：反手哑铃夹胸4*10-15
2. 背
   1. 上背：正手划船4*10-15
   2. 中背：对握划船4*10-15
   3. 下背：半程硬拉4*10-15
   4. 侧背：单臂划船4*10-15
3. 肩
   1. 力量：推举
   2. 前束：交替前平举
   3. 中束：侧平举
   4. 后束：俯身提拉
4. 臂
   1. 饱满：正手弯举
   2. 肱：锤式弯举
   3. 三头：颈后臂屈伸
   4. 三头外侧：俯身臂屈伸
5. 臀腿腰腹
   1. 腿前：负重深蹲
   2. 腿后：直腿硬拉
   3. 力量：负重弓步蹲
   4. 腹：坐姿举腿
   5. 侧腹：侧向卷腹
6. 歇两天
